AI destekli akıllı personel giriş ve güvenlik sistemi MVP'si.

## Özellikler
- Ana landing sayfası
- Dashboard görünümü
- Güvenlik merkezi
- Supabase hazırlık yapısı
- AI destekli güvenlik önerileri endpoint'i

## Teknoloji Stack
- Next.js 14
- Tailwind CSS
- TypeScript
- Supabase
- Vercel

## Kurulum
1. Bağımlılıkları kur:
   ```bash
   npm install
   ```
2. Ortam değişkenlerini ayarla:
   ```bash
   cp .env.example .env.local
   ```
3. Geliştirme sunucusunu başlat:
   ```bash
   npm run dev
   ```

## GitHub ve Vercel
- GitHub repo oluşturup bu klasörü bağla:
  ```bash
  git init
  git add .
  git commit -m "Initial commit"
  git branch -M main
  git remote add origin https://github.com/<kullanici-adiniz>/nexivor.git
  git push -u origin main
  ```
- Vercel'de proje ekleyip Supabase ortam değişkenlerini ekle.
